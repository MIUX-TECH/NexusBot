# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1a1CDCVLeR1pUbQqHw29qMVBEm7D2xIZW

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. (Opsional) Set `GEMINI_API_KEY` di [.env.local](.env.local) jika ingin auto-load.
3. Jalankan aplikasi:
   `npm run dev`
4. Masukkan API Key Binance dan Gemini secara manual melalui menu **Koneksi API**.
